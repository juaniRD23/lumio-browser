## Setup
1. `git fetch origin batch5-organize && git checkout batch5-organize` (the clone may start on another branch). Work only on this branch.
2. Install: `npm ci` (if Electron's binary download fails, `ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm ci` — the unit tests don't need Electron). Then `npm run build:preload` if package.json has it / whatever `npm test` expects (read package.json). Server: `cd server && npm ci`.
3. The headless UI tests launch Chrome from /usr/bin/google-chrome (see tests/shell.test.mjs). If it's missing, install a browser: `npx playwright install --with-deps chromium` and link it: `sudo ln -sf "$(ls -d ~/.cache/ms-playwright/chromium-*/chrome-linux*/chrome | head -1)" /usr/bin/google-chrome` (or apt-get install google-chrome-stable / chromium). Fonts may differ from macOS — don't chase pixel differences caused only by fonts.
4. Run `npm test` once before changing anything and note the counts (some failures may come from the partial WIP commit — those are yours to fix). `npm test` must pass at the end (and `npm test` in server/ if you touch the server).
